# Demo pública del SIMP Salaverry

Demostración estática del flujo de mantenimiento preventivo. Los equipos y materiales son ficticios. Las lecturas, las evidencias opcionales y los cambios de prueba se conservan en el navegador que los registra. Cada visitante tiene su propia bitácora de prueba.

GitHub Pages publica la carpeta raíz de `main`. La aplicación original con FastAPI y SQLite se ejecuta por separado.
